# Pavilion Delight Menu

Build a premium mobile-first QR menu website for Pavilion All Day Dining, Indore. Use a warm luxury hotel aesthetic with elegant typography, cream, gold and deep green colors. Inspired by user reviews: family-friendly ambience, buffet, hygienic dining, courteous staff, comfortable seating. Include: hero with restaurant branding, category navigation, menu sections (Soups, Starters, North Indian, Chinese, Pasta, Pizza, Rice & Noodles, Breads, Desserts, Beverages), search, veg/non-veg indicators, popular dishes, chef recommendations, gallery placeholders, customer review highlights, contact/location, opening hours, QR optimized layout, sticky order-free browsing experience, responsive design, subtle animations, accessible UI, Tailwind + shadcn components. Use placeholder prices and structure so they can be edited easily later.
